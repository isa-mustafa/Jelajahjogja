# Jelajah Jogja

Website statis berbahasa Indonesia untuk mengenal destinasi wisata Yogyakarta. Pengunjung dapat melihat peta wisata interaktif, membaca informasi Candi Prambanan, Keraton Yogyakarta, dan Pantai Parangtritis, serta membuka halaman kontak.

## Menjalankan secara lokal

Buka `index.html` di browser. Situs ini menggunakan HTML, CSS, dan ilustrasi SVG tanpa dependensi atau proses build.

## Deployment

Workflow GitHub Actions di `.github/workflows/deploy.yml` menerbitkan situs ke GitHub Pages setiap kali ada perubahan di branch `main`. Setelah workflow pertama berhasil, alamat situs tersedia pada bagian **Settings → Pages** repository.
